# Patient Health Deterioration Prediction

## Project Overview

In this project, I used Machine Learning and Artificial Intelligence techniques to predict patient health deterioration using medical data such as blood sugar levels and blood pressure.

The main goal of the project is to help hospitals monitor patients more accurately and detect dangerous health conditions early.

I trained and compared different machine learning models to find which model gives the best prediction performance.

---

## Dataset

The dataset contains medical information related to patient health conditions. Before training the models, I cleaned and prepared the data to improve the prediction accuracy.

Because the dataset size is very large, I could not upload it to this repository.

---

## Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Scikit-learn
* TensorFlow / Keras

---

## Models Used

In this project, I used and compared the following models:

1. Logistic Regression
2. Random Forest
3. K-Nearest Neighbors (KNN)
4. Neural Network (TensorFlow/Keras)

---

## Results

After comparing the models, KNN achieved the best overall performance with the highest Accuracy and F1-score.

Random Forest also produced strong and stable results, while Logistic Regression achieved good performance but lower than KNN.

The Neural Network achieved acceptable Accuracy, but the Precision and Recall values were low, which means it failed to detect many positive cases.

This project showed me that high Accuracy alone does not always mean a model performs well.

* How to evaluate models using Accuracy, Precision, Recall, and F1-score
